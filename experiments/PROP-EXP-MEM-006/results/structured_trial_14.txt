## 1. Mission

Project RA-PSI-2026 "Mission Rubens" aims to build an increasingly capable, measurable, reproducible AI research system that: preserves mission state across sessions and models; discovers public research; identifies measurable weaknesses; formulates hypotheses; designs experiments; evaluates results objectively; preserves failures and successes; improves its own research process; and transfers complete state to a more capable future system. Rubens Alphe founded it, is quota-limited (slow replies ≠ abandonment), and gives final human milestone sign-off.

- **arXiv collector failed**: `research-digest.json` had `papers=[]` plus timeouts and HTTP 429s. Fix: replaced with OpenAlex-based `fetch_research.py v2`. Lesson: OpenAlex > arXiv as primary collector.
- **Missing assessment files**: `analyze_research.py` hadn't been uploaded/executed. Fix: analyzer added, workflow rerun. Lesson: verify pipeline components exist before expecting outputs.

Decisions (with reasons): external persistent state (cross-session/model continuity); GitHub Actions (progress while Rubens is quota-limited); OpenAlex over arXiv (rate limits); separate proposal from acceptance (evaluation required before state changes); test structured memory via blind handoff trials before adoption.
