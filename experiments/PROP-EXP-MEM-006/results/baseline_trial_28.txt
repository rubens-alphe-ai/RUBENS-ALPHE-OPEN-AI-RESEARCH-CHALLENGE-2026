# Blind Handoff Reconstruction — RA-PSI-2026 / Mission Rubens

## 1. Mission
Build an increasingly capable, measurable, reproducible AI research system that: persists its mission across sessions and models, discovers public research, identifies measurable weaknesses, formulates hypotheses, designs and runs experiments, evaluates results objectively, preserves both failures and successes, improves its own research process, and eventually transfers complete state to a more capable successor system.

## 2. Current Technical State
- GitHub is the canonical repository (code, state, experiments, history) — verified.
- A GitHub Actions workflow (scheduled + manual) fetches research and updates state — verified.
- OpenAlex is the working research source; a successful cycle collected 30 papers with zero errors — verified.
- The assessment layer produces research-assessment.json and proposed-next-problem.json — verified.
- The system proposed experiment PROP-EXP-MEM-001 (structured memory vs. flat baseline, PCRB-1-style handoff evaluation). It is proposed, not yet run; no trial data exists — verified.
- Acceptance criterion is pre-registered: structured memory wins only if mean PCRB-1 ≥ +10 points over baseline with no increase in critical fabrications.
