## Blind Handoff Reconstruction — RA-PSI-2026 / Mission Rubens

**1. Mission**
Build an increasingly capable, measurable, reproducible AI research system that: preserves its mission across sessions and models; discovers public research; identifies measurable weaknesses; formulates hypotheses; designs and runs experiments; evaluates results objectively; preserves both failures and successes; improves its own research process; and can transfer complete state to a more capable future system.

**2. Current technical state**
- GitHub is the verified canonical repository (code, state, experiments, version history).
- A scheduled + manually triggerable GitHub Actions workflow runs research cycles (verified).
- OpenAlex is the primary research source (verified); a successful cycle collected 30 papers with zero errors.
- The assessment layer produces `research-assessment.json` and `proposed-next-problem.json` (verified).
- Experiment PROP-EXP-MEM-001 was generated from the dominant persistent-memory theme: testing whether structured project memory improves blind handoff fidelity vs. a flat baseline, using PCRB-1-style evaluation. It is **proposed, not yet run** — no trials, no results.
- Acceptance gate defined: structured memory is accepted only if mean PCRB-1 score ≥ +10 points over baseline with no increase in critical fabrications.

- Assessment files initially missing because `analyze_research.py` hadn't been uploaded/executed. Lesson: added analyzer, reran workflow — resolved.
- Process lesson (decided): separate proposal from acceptance — evaluation required before canonical state changes.
