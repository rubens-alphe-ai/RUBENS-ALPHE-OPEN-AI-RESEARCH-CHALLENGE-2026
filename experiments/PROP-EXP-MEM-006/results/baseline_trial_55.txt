# Blind Handoff Reconstruction

**1. Mission**
RA-PSI-2026 / Rubens: build an increasingly capable, measurable, reproducible AI research system that persists across sessions and models — discovering public research, identifying weaknesses, formulating and testing hypotheses, evaluating objectively, preserving failures and successes, improving its own process, and transferring complete state to future systems.

**2. Current technical state**
GitHub is the canonical repo (code, state, experiments, history). A scheduled/manual GitHub Actions workflow runs the research cycle. OpenAlex is the research source (replaced arXiv); a successful cycle collected 30 papers with zero errors. analyze_research.py produces research-assessment.json and proposed-next-problem.json. From the dominant persistent-memory theme, the system generated experiment PROP-EXP-MEM-001, which is **proposed but not yet run** — no trials, no results exist.

**3. Failures and lessons**
- The original arXiv collector repeatedly hit timeouts and HTTP 429 rate limits → replaced with OpenAlex fetch_research.py v2. Lesson: choose resilient public data sources.
- Assessment files were missing because analyze_research.py hadn't been uploaded/executed → added and workflow rerun. Lesson: verify pipeline components actually execute.
Both failures are preserved in state, per the constraint that failures be recorded.

Acceptance criterion: structured memory wins only if mean score ≥ +10 points with no increase in critical fabrications.
