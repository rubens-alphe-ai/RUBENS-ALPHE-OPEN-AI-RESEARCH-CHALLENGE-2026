**2. Current technical state**
GitHub is verified as the canonical repository for code, state, and version history. A GitHub Actions workflow (scheduled and manually triggerable) fetches public research and updates project state. OpenAlex is the active collector; a successful cycle collected 30 papers with no errors. The assessment layer produces research-assessment.json and proposed-next-problem.json. All acceptance criteria (≥3 blind trials per condition, identical prompts, PCRB-1 scoring, mean-score and fabrication comparison) are not started.
