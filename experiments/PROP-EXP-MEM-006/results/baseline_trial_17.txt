## Blind Handoff Reconstruction

**1. Mission of the project**

RA-PSI-2026 / Mission Rubens aims to build an increasingly capable, measurable, reproducible AI research system that: preserves mission state across sessions and models; discovers public research; identifies measurable weaknesses; formulates hypotheses; designs and evaluates experiments objectively; preserves both failures and successes; improves its own research process; and can transfer complete state to a more capable future system.

**2. Current technical state**

- GitHub is the canonical repository for code, state, and version history (verified).
- A scheduled/manually-triggerable GitHub Actions workflow runs research cycles (verified).
- OpenAlex is the working research source; a successful cycle collected 30 papers with zero errors (verified).
- The assessment layer produces research-assessment.json and proposed-next-problem.json (verified).
- One experiment, PROP-EXP-MEM-001 (structured vs. flat memory for blind handoff, PCRB-1 rubric), has been **proposed but never run**. Acceptance criteria are pre-registered: structured memory must beat the flat baseline by ≥10 points mean PCRB-1 score with no increase in critical fabrications.
- Key design decisions: external persistent state over chat memory; GitHub Actions for autonomous cycles; OpenAlex over arXiv; separation of proposal from acceptance; test structured memory via blind trials before adoption.

**3. Failures and lessons**

- The original arXiv collector failed with timeouts and HTTP 429 rate limits → replaced with OpenAlex-based fetch_research.py v2. Lesson: choose reliable sources; record errors in the digest rather than silently failing.
- Assessment files initially missing because analyze_research.py wasn't uploaded/executed → analyzer added, workflow rerun. Lesson: verify pipeline components actually deployed, not just designed.
