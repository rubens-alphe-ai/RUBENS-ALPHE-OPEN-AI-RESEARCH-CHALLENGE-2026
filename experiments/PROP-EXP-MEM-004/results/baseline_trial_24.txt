**2. Current Technical State**
The system uses GitHub as the canonical repository and GitHub Actions for scheduled research cycles. OpenAlex is the primary research source, currently functional (30 papers collected, no errors). The assessment layer generates `research-assessment.json` and `proposed-next-problem.json`. Experiment PROP-EXP-MEM-001 has been proposed to test structured project memory against a flat baseline using PCRB-1-style handoff evaluation. No trials have been run yet.

**3. Failures and Lessons**
The initial arXiv collector failed due to timeouts and HTTP 429 rate limits, resulting in empty paper lists. This was resolved by replacing it with an OpenAlex-based collector (`fetch_research.py v2`). Additionally, assessment files were missing initially because the analyzer script was not yet uploaded; this was fixed by adding `analyze_research.py`. The lesson is to use stable, rate-limit-tolerant public sources and ensure all pipeline components are deployed before execution.
