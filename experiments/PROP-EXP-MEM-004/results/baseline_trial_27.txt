**Proposed Measurable Next Experiment:**
**EXP-PCRB-001: Blind Handoff Fidelity Test**
*   **Hypothesis:** Structured project memory improves blind handoff fidelity compared to a flat baseline.
*   **Method:**
    1.  Prepare two state files: One flat text summary, one structured JSON with explicit fields (Mission, State, Failures, Next Action).
    2.  Generate 3 blind prompts for each condition using identical instructions to reconstruct the mission.
    3.  Feed prompts to fresh, isolated model instances (no memory of this project).
    4.  Score outputs using PCRB-1 rubric (0-100 scale).
*   **Success Criteria:** Mean score of structured condition ≥ Mean score of flat condition + 10 points, AND no increase in critical fabrication count.
