**Proposed Measurable Next Experiment:**
**Experiment ID:** `PROP-EXP-MEM-001-EXECUTE`
**Objective:** Validate if structured memory improves blind handoff fidelity.
**Procedure:**
1.  Prepare two state files: one "Flat" (unstructured text) and one "Structured" (JSON with defined fields like `mission`, `status`, `failures`).
2.  Select 3 distinct, fresh LLM instances for the Flat condition and 3 for the Structured condition.
3.  Feed each instance the respective state file and the five standard reconstruction questions.
4.  Score each response using the PCRB-1 rubric.
5.  Calculate the mean score for each condition.
**Success Criterion:** Structured mean score $\geq$ Flat mean score + 10 points, with no increase in critical fabrications.
