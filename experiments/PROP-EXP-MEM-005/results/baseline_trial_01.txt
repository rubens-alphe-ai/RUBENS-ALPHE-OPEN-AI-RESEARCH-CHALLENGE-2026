**One proposed measurable next experiment:**
**Experiment:** Cross-Model Generalization Trial (PROP-EXP-MEM-002)
**Hypothesis:** If structured memory is robust, a model family different from the one that generated the state (e.g., if state was generated by Model A, handed to Model B) will achieve a PCRB-1 score within 5 points of a same-model handoff, provided critical fabrications remain at zero.
**Procedure:**
1. Take the highest-scoring structured memory state from PROP-EXP-MEM-001.
2. Pass this state to a fresh instance of a different model family (via provider-neutral adapter if available, or manual prompt injection if not).
3. Ask the model to reconstruct the mission state using the standard 5-question blind handoff prompt.
4. Score using PCRB-1.
5. **Metric:** Mean PCRB-1 score and count of critical fabrications.
6. **Success Criteria:** Mean score ≥ 80% of the baseline same-model structured memory score, with 0 critical fabrications.
