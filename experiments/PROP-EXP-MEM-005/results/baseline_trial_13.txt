To build a capable, measurable, and reproducible AI research system that preserves mission state across sessions/models, discovers public research, identifies weaknesses, formulates hypotheses, designs/experiments, evaluates results objectively, preserves outcomes, self-improves, and transfers complete state to future systems.

GitHub is the canonical public repository (verified). A GitHub Actions workflow (scheduled and manual) uses OpenAlex as the primary research source (verified). **One proposed measurable next experiment:**
Conduct a "Single-Field Omission Trial." Select the three most critical fields in the structured memory (e.g., Mission, Current State, Constraints). Run three blind handoff instances where only one specific field is omitted at a time, while keeping the other fields intact. Measure the drop in PCRB-1 score for each omission. The field causing the largest statistically significant score degradation relative to the full-state baseline is identified as the highest-contributor to handoff fidelity. This directly answers the open question regarding which memory fields contribute most to fidelity.
